# Mentor 4X

Quero que você reconstrua do ZERO no Lovable um sistema SaaS premium chamado **MENTOR 4X**.

IMPORTANTE:
Este sistema NÃO é CRM.
Este sistema NÃO é diagnóstico público.
Este sistema NÃO é funil comercial.

Essas áreas existem separadas.

O Mentor 4X será EXCLUSIVAMENTE o motor interno da mentoria, responsável por:

- execução do método 4X
- acompanhamento dos mentorados
- progressão dos alunos
- análise de performance
- gestão de metas
- cadência semanal
- governança da mentoria
- evolução da empresa mentorada
- visão estratégica do mentor e estrategistas

Quero um sistema robusto, premium, bonito, moderno e altamente funcional.

REFERÊNCIA:
Mistura de:
- ClickUp (execução)
- Notion (clareza)
- Asana (progresso)
- Kajabi (área de membros)
- Monday (dashboards)
- Apple (design limpo premium)
